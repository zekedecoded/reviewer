01 Operating System Utilities
ping
Sends ICMP echo requests to a host to test if it is reachable and measure round-trip time.
ipconfig
Windows command that displays IP address, subnet mask, and default gateway of network adapters.
ip
Linux command used to display and manage IP addresses, routes, and network interfaces.
arp
Address Resolution Protocol tool; shows or modifies the mapping between IP addresses and MAC addresses.
netstat
Displays active network connections, open ports, and protocol statistics on a host.
nslookup
DNS query tool used to look up IP addresses or domain names from a DNS server.
02 Network Scanning & Analysis
Network Scanner
An inventory tool that queries hosts on a LAN using TCP/IP protocols to discover IP addresses, MAC addresses, open ports, and OS information.
Baseline
A network asset verification that documents every device (servers, printers, routers, switches, WAPs) on the network — the "official" inventory.
Simple Scanner
Fast, lightweight scanner (e.g., Angry IP Scanner) that does basic ping-based scans and needs minimal resources.
Powerful Scanner
A scanner using multiple protocols to dig deeply into a network and return large amounts of detailed data.
Protocol Analyzer
Hardware or software that captures and analyzes network traffic; also called a packet analyzer. Used to inventory and inspect Ethernet frames and IP packets.
Wireshark
The most popular open-source packet analyzer (originally Ethereal, 1998). Shows three panes: frame list, frame details, and raw hex data.
TShark
Command-line version of Wireshark; captures packets to a .pcap file without a GUI — ideal for scheduled/overnight captures.
SNMP
Simple Network Management Protocol; used by network devices to send performance and security event data for monitoring.
SIEM
Security Information and Event Management; system that collects, correlates, and analyzes log data from multiple network sources to detect security incidents.
Event Log
Windows OS-generated logs (called syslogs or machine logs in Linux) recording system and application activity.
Audit Log
Security or audit trails stored by the OS; also called audit trails — used by security professionals to trace security-related events.
Log Analysis
Reviewing log files to find specific security events and correlate them into a pattern that indicates a problem over a time frame.
Centralized Log Management
Automatically collects and sends log files from multiple machines to a central server for easier review.
Decentralized Log Management
Admin manually visits each host to collect and review logs — common in small networks or disconnected segments.
03 Attacks System
Man-in-the-Middle (MitM)
Attacker secretly intercepts communication between two parties, often targeting apps with weak or no authentication.
Zero-Day Attack
An attack exploiting a previously unknown and unpatched vulnerability before developers can release a fix.
Privilege Escalation
Attacker gains higher-level access than originally authorized, often using a low-level or service account to reach admin-level control.
IP Spoofing
Replacing a legitimate IP address with a fake one to disguise the attacker's identity or impersonate another host.
MAC Spoofing
Same concept as IP spoofing, but targeting MAC addresses to impersonate a trusted device on the network.
ARP Poisoning
Flooding the network with fake ARP replies to corrupt ARP tables, redirecting traffic through the attacker's machine.
DoS (Denial of Service)
Attack that overwhelms a program, OS, or server with traffic or requests to shut it down and deny access to legitimate users.
Refactoring (Malicious)
Modifying the internals of software (e.g., a driver) without changing its visible behavior — used to sneak in malicious code.
Shimming
Inserting a malicious library (shim) between the OS and a driver to intercept and manipulate data without replacing the signed driver.
Virus
Malware that requires a user action to spread (e.g., opening an infected file). Can infect directories or boot sectors.
Crypto-malware / Ransomware
Uses cryptography to lock a user out of their device and demands payment to decrypt it.
Worm
Self-replicating malware that spreads automatically across a network with little or no user interaction.
Trojan Horse
Malware disguised as a legitimate program (game, utility). Typically tries to harvest personal data from the victim.
Rootkit
Malware that infects core OS files, hides itself from antivirus tools, and can conceal other malware on the host.
Keylogger
Records every keystroke and sends them to an attacker. Symptoms include slowdowns and unusual network traffic.
Adware
Malware that displays unwanted pop-up ads, often to drive the user to visit a site or buy a product.
Spyware
Secretly monitors user activity and sends data back to the attacker without the victim's knowledge.
Botnet
A network of malware-infected computers (bots) controlled remotely to launch large-scale attacks on systems or networks.
Logic Bomb
Malicious script set to execute at a specific time or when certain conditions are met (e.g., a scheduled task).
Backdoor
An unauthorized hidden entry point into software, often left during development, that bypasses normal authentication.
RAT (Remote Admin Tool)
Software that gives an attacker remote access to a victim's computer; commonly used as part of a botnet.
Bluejacking
Sending unsolicited messages (texts, images) to a nearby Bluetooth-enabled device.
Bluesnarfing
Attacker steals data from a victim's device by connecting to it via Bluetooth without authorization.
04 Strengthening Redundancy & Availability
Non-persistence
A system design strategy where changes (including from attacks) are rolled back instead of persisting — via snapshots, rollbacks, or live boot.
Snapshot
A saved state of a VM at a specific point in time; allows rollback to that state if the system is compromised or corrupted.
Revert / Rollback
Returning an OS to a previously saved state (restore point in Windows) to undo damage from an attack or bad update.
Live Boot Media
A bootable OS on removable media (e.g., Kali Linux USB) that runs independently — no hard drive required on the host.
Redundancy
Having duplicate systems, storage, or network paths so a failure in one does not stop overall operations.
RAID
Redundant Array of Independent Disks — spreads data across multiple drives for fault tolerance and/or performance.
Striping
Writing pieces of data across two or more physical disks simultaneously for faster read/write speeds (no redundancy by itself).
Mirroring
Duplicating data exactly on two disks so if one fails, the other has a complete copy (full redundancy, uses double space).
Parity
Extra data stored across disks that allows the array to reconstruct a failed drive's data without keeping a full mirror copy.
Load Balancing
Distributes incoming requests across multiple servers so no single server is overwhelmed; increases performance and availability.
Clustering
Running multiple identically-configured servers together; if one fails, the others continue operating without user interruption (fault tolerance).
Elasticity
Ability to automatically add or remove server instances based on current demand (used in virtualization/cloud environments).
EMI (Electromagnetic Interference)
When one device's electromagnetic field disrupts another — causes slow data transmission but rarely destroys hardware.
EMP (Electromagnetic Pulse)
A burst of electrical energy through the air that can permanently destroy unprotected electronic circuits and computer components.
RFI (Radio Frequency Interference)
EMI that operates in the radio frequency range (e.g., 802.11 and cellular bands); typically disrupts other radio sources.
TPM (Trusted Platform Module)
A chip on modern computers that stores cryptographic keys and verifies system integrity during boot to ensure firmware hasn't been tampered with.
BitLocker
Windows Pro's Full Disk Encryption (FDE) tool; uses TPM to encrypt the entire drive so data is unreadable without proper authentication.
SED (Self-Encrypting Drive)
A drive with built-in circuitry that automatically encrypts and decrypts all data — no software FDE tool needed.
HSM (Hardware Security Module)
A dedicated hardware device that performs cryptographic operations hundreds of times faster than a standard CPU — used for key management.
DMZ (Demilitarized Zone)
A separate network segment between the public internet and internal LAN, hosting public-facing servers (web, email) to limit exposure of internal systems.
NAT (Network Address Translation)
Maps private internal IP addresses to one or more public IPs, hiding internal network structure and conserving public IP space.
VLAN (Virtual LAN)
Logically separates hosts on the same physical switch into isolated broadcast domains — improves security and reduces unnecessary traffic.
NAC (Network Access Control)
Checks a device's health/security settings before allowing it onto the network — can use agents or be agentless.
Patch Management
A formal process of testing and applying OS/software updates to fix vulnerabilities — should be tested on systems before enterprise-wide deployment.

05 Information Security Fundamentals
CORE Core Concepts & CIA Triad
Data
Raw, unorganized facts — numbers, text, symbols — that have no meaning on their own until they are processed. Example: 90, 85, 88.
Information
Processed data that has meaning and value. Example: "Average grade is 87.6" derived from the raw scores 90, 85, 88.
Information Security
The practice of protecting information from unauthorized access, use, disclosure, disruption, modification, or destruction — protecting data from being seen by the wrong people, changed, or lost.
Information Value
How important or sensitive data is to an individual or organization. Higher value means higher protection is needed. Example: public posts = low value; passwords and bank details = high value.
Public Information
Data classified as accessible to everyone — requires the least security protection.
Private Information
Data with limited access — not meant for public disclosure and requires moderate protection.
Confidential Information
Highly restricted data — requires the strongest security controls to prevent unauthorized access.
Information Security Model
A structured framework used to guide how information is protected — organizes security strategies and provides a systematic approach.
CIA Triad
The core model of Information Security consisting of three fundamental principles: Confidentiality, Integrity, and Availability.
Confidentiality (CIA)
Ensures that information is accessible only to authorized users. Methods include passwords, encryption, and access control.
Integrity (CIA)
Ensures that information is accurate, complete, and not altered without authorization. Examples: grades not changed, files not corrupted.
Availability (CIA)
Ensures that information and systems are accessible when needed by authorized users. Examples: websites staying online, systems working properly.
Authentication
Verifying the identity of a user or system — answering "Who are you?" Example: username and password login.
Authorization
Determining what an authenticated user is allowed to do. Example: Admin vs. Student permissions on a system.
Non-repudiation
Ensuring that an action or transaction cannot be denied after the fact. Example: system logs that record and prove who did what.
Components of InfoSec (People)
Users and individuals involved in handling and protecting information — one of the three main components of Information Security.
Components of InfoSec (Processes)
Rules and procedures that govern how information is managed and protected — one of the three main components of Information Security.
Components of InfoSec (Technology)
Hardware and software tools used to enforce security — one of the three main components of Information Security.
Security Lifecycle
A four-phase model describing how organizations handle threats: Protect (prevent attacks) → Detect (identify threats) → React (respond to incidents) → Recover (restore systems).
Why InfoSec Matters
Information security protects personal and sensitive data, prevents financial loss, maintains trust in systems, and ensures continuous operations.
Goals of InfoSec
Three goals: protect data from threats (safety of data), ensure systems function properly (reliability of systems), and prevent unauthorized access (controlled access).
InfoSec Success Factors
Success in Information Security depends on: user awareness, strong policies, updated systems, and continuous monitoring.
NET Network Security & Access Controls
Firewall
Device or software that inspects IP packets and filters them based on rules (port, IP, protocol, time) to block unauthorized traffic.
Stateless Firewall
Oldest firewall type (packet filter); uses an ACL to block/allow packets based on fixed criteria without tracking connection state.
Stateful Firewall
Tracks the state of connections (e.g., TCP handshake) and only allows packets that are part of an established, legitimate session.
Proxy Server
An intermediary that accepts client requests, processes them, and forwards them to servers — used to enforce policies and hide internal systems.
Forward Proxy
Sits between clients and the internet; enforces outbound access policies (e.g., blocking URLs or limiting hours).
Reverse Proxy
Sits in front of servers; filters incoming requests to protect servers from attacks before forwarding good traffic.
Implicit Denial
ACL default behavior — unless a rule explicitly allows traffic, it is blocked. "Deny all unless permitted."
HIDS
Host-Based Intrusion Detection System — detects intrusions on a host and reports them (does not block).
HIPS
Host-Based Intrusion Prevention System — actively blocks detected intrusions, not just reporting them.
Anti-malware
Modern security software with real-time scanning of incoming data, checking for known malware signatures in emails and web traffic.
DEP (Data Execution Prevention)
Windows feature using the CPU's NX bit to prevent code from running in data-only memory areas — stops buffer overflow exploits.
File Integrity Check
Verifies that files haven't been tampered with by comparing hashes, timestamps, version numbers, and digital signatures against known-good values.
DLP (Data Loss Prevention)
Tools that monitor and control data movement to ensure sensitive data isn't copied, moved, or leaked outside the organization.
Application Whitelisting
Only pre-approved applications are allowed to run or install on a system — everything else is blocked by default.
Application Blacklisting
Identified dangerous or unwanted applications are blocked; everything not on the list is allowed.
Trusted OS
An OS designed and certified for high-security environments (e.g., SE Linux, Trusted Solaris, Trusted AIX, Windows 10).
Clear (Data Sanitation)
Overwriting storage media using built-in device commands or disk wiping utilities (e.g., single overwrite with binary zeros).
Purge (Data Sanitation)
Destroying data using methods beyond basic commands — degaussing (for HDDs only) or eliminating encryption keys on encrypted media.
Destroy (Data Sanitation)
Physically destroying the storage media itself — the most thorough method; professional shredding/destruction services available.
WEP
Wired Equivalent Privacy — first 802.11 wireless security standard; uses RC4 but was mathematically broken within years. Now obsolete.
WPA
Wi-Fi Protected Access (2003); improved on WEP with larger, dynamic keys using TKIP. Has Personal (PSK) and Enterprise (RADIUS) modes.
WPA2
Final implementation of IEEE 802.11i; uses AES/CCMP encryption — the strongest standard for most current networks.
AES
Advanced Encryption Standard; uses the Rijndael algorithm with 128-bit keys and block size — the encryption method in WPA2 (via CCMP).
TKIP
Temporal Key Integrity Protocol; WPA's dynamic per-packet key generation system using RC4 — adds randomness to prevent key reuse.
RC4
Stream cipher used in WEP and WPA; strong on its own but WEP's poor implementation (weak IVs, static keys) made it exploitable.
WPS
Wi-Fi Protected Setup; lets devices connect via a button push, but its 8-digit PIN (only ~11,000 combinations) is easily brute-forced.
802.1X
Port-based network access control framework supporting multiple authentication protocols — used in enterprise wired and wireless networks.
EAP
Extensible Authentication Protocol; a flexible authentication framework (not a single protocol) supporting certificates, smart cards, and username/password.
EAP-TLS
Most secure EAP variant; requires digital certificates on both client and server sides for mutual authentication.
EAP-TTLS
Adds a TLS tunnel for protection; only requires a server-side certificate (not client-side).
PEAP
Protected EAP; creates a TLS tunnel using a server-side certificate, then authenticates the client inside the tunnel.
LEAP
Lightweight EAP — a Cisco proprietary protocol using dynamic WEP keys and RADIUS. Now replaced by EAP-FAST due to security flaws.
EAP-FAST
Cisco's replacement for LEAP; uses TLS tunnels for secure, lightweight authentication.
Rogue Access Point
A fake WAP set up by an attacker to lure users into connecting — all their traffic is then intercepted and monitored.
Evil Twin Attack
A variant of the rogue AP attack where the attacker's AP uses the same (or similar) SSID as the legitimate network.
Deauthentication Attack
Forcing a wireless client to disconnect from the WAP so it must reconnect — allowing the attacker to capture the handshake for cracking.
Replay Attack
Intercepting credentials or data and retransmitting them later to impersonate the victim — effective against plain-text or weakly encrypted traffic.
NFC (Near Field Communication)
Short-range radio communication (using RFID) that requires devices to be very close or touching — vulnerable to relay, MitM, and jamming attacks.
Packet Sniffing
Capturing and reading unencrypted wireless or wired network traffic — requires a NIC in promiscuous mode and tools like Wireshark.
Jamming
Intentional DoS attack on wireless networks — overwhelms the radio signal to prevent legitimate devices from communicating.
SSID Broadcasting
A WAP advertising its network name so devices can find it. Disabling it (cloaking) adds minor obscurity but is not a real security control.
MAC Filtering
Restricting wireless access to only approved MAC addresses. Easy to bypass via MAC spoofing — not a standalone security measure.
Captive Portal
A web page that wireless users must authenticate through before they can access the network (used in hotels, enterprises, airports).
Fat AP
A "thick" access point with full built-in controls (ACLs, encryption settings, etc.) — each is managed individually or via a central console.
Thin AP
A simple repeater AP that forwards wireless signals to a centralized Access Controller (AC) which handles encryption and security.
Site Survey
A technical review of a wireless network's coverage, interference sources, antenna placement, and capacity — done before or during network deployment.
O-TTPS
Open Trustworthy Technology Vendor Standard; a framework for securing the ICT supply chain for hardware and software products.
Degaussing
Using a powerful magnetic field to permanently erase data on HDDs. Destroys the drive in the process; has no effect on SSDs.
Flood Guard
A switch/router feature that detects and stops traffic floods (used in DoS attacks) by blocking malformed or excessive traffic.
STP (Spanning Tree Protocol)
Standard switch protocol that prevents network loops by allowing switches to communicate and automatically block redundant paths.
